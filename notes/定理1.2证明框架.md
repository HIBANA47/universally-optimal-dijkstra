# 定理 1.2 证明框架

> **定理 1.2**：使用任何具有工作集性质的类 Fibonacci 优先队列实现的 Dijkstra 算法，在比较-加法模型中是距离排序问题的普适最优算法（运行时间方面）。

## 证明总览

定理 1.2 的证明由两条核心线索构成：

```
上界（算法代价）  ←  匹配  →  下界（信息论下界）
     ↑                              ↑
 命题 3.2                        引理 3.6
 DeleteMin 总代价                障碍序列 → 排序下界
 = O(OPT_Q(G) + n)              → Ω(Σ|Bᵢ|log|Bᵢ|)
```

最终通过**引理 3.12**（好的着色蕴含最优性）和**引理 3.14**（贪婪着色总是好的）完成匹配。

---

## 第一步：化约为命题 3.2

**目标**：证明 Dijkstra + 工作集堆的时间复杂度 = $O(OPT_Q(G) + m + n)$

**关键观察**：
- Insert / DecreaseKey 每次 $O(1)$，共 $O(n)$ 次 Insert，至多 $\max_w |F_{G,w}|$ 次 DecreaseKey
- DeleteMin 是代价的主要来源
- 因此只需证明：**所有 DeleteMin 的总摊销代价 = $O(OPT_Q(G) + n)$**（命题 3.2）

**为什么这蕴含定理 1.2**（附录 E，引理 E.1）：
- $OPT_Q(G) + m + n = O(OPT_T(G))$，因为：
  - 每次比较需要单位时间 → $OPT_Q(G) \leq OPT_T(G)$
  - 输出大小为 $\Omega(n)$ → $OPT_T(G) = \Omega(n)$
  - 算法必须读所有边 → $OPT_T(G) = \Omega(m)$

---

## 第二步：建立下界框架（信息论 → 障碍序列）

### 2.1 熵论证（引理 3.3）

每次比较查询返回 $\{-1, 0, 1\}$ 三种结果之一，仅恢复 $\log 3$ 位信息。

$$OPT_Q(G) = \Omega(\log(Linearizations(G)))$$

**含义**：任何算法的比较次数 ≥ 可能输出数量的对数。

### 2.2 障碍序列下界（引理 3.6）

**障碍**：树 T 中节点的不可比集合（无祖先-后代关系）

**障碍序列** $(B_1, ..., B_k)$：满足 $i < j$ 时 $B_i \prec B_j$（$B_j$ 的节点不是 $B_i$ 节点的前驱）

**核心作用**：每个障碍 $B_i$ 对应一个独立的排序子问题，需要 $\Omega(|B_i| \log |B_i|)$ 次比较。

$$\log(Linearizations(G)) \geq \Omega\left(\sum_{i=1}^{k} |B_i| \log |B_i|\right)$$

---

## 第三步：区间形式化（将图问题转化为着色问题）

### 3.1 Dijkstra 诱导的区间集（定义 3.7）

每个顶点 $v$ 对应一个时间区间 $\iota(v) = [l_v, r_v]$：
- $l_v$：$v$ 被首次发现并插入堆的时刻
- $r_v$：$v$ 从堆中被提取的时刻

### 3.2 区间工作集（定义 3.8-3.9）

区间 $x$ 在时间 $t$ 的工作集：
$$W_{x,t} = \{y \in I \mid l_x \leq l_y \leq t \leq r_y\}$$

$x$ 的代价：$cost(x) = \log |W_x|$，总代价：$cost(I) = \sum_{x \in I} \log |W_x|$

**关键对应**：$cost(I)$ 渐近等于所有 DeleteMin 操作的总摊销代价。

### 3.3 相交着色与能量（定义 3.10）

**k 色相交着色**：为每个区间分配颜色，使得同色区间有非空交集。

**能量**：$E(C) = \sum_{i=1}^{k} c_i \log c_i$，其中 $c_i$ 是第 $i$ 种颜色的区间数。

**关键对应**：每种颜色对应探索树中的一个障碍，因此 $E(C)$ 给出 $OPT_Q(G)$ 的下界。

---

## 第四步：匹配上下界（核心论证）

### 4.1 着色给出下界（引理 3.11）

$$\log(Linearizations(G)) \geq \Omega(E(C))$$

### 4.2 好的着色蕴含最优性（引理 3.12）

> **如果存在着色 $C$ 使得 $E(C) \geq cost(I)$，则 DeleteMin 总代价 = $O(OPT_Q(G) + n)$**

逻辑链：
$$E(C) \geq cost(I) \implies OPT_Q(G) \geq \Omega(cost(I)) \implies cost(I) = O(OPT_Q(G))$$

### 4.3 贪婪着色总是好的（引理 3.14）⭐

> **对任何区间集 $I$，存在相交着色 $C$ 使得 $E(C) \geq cost(I)$**

**证明**（归纳法）：
1. **选取**：找到具有最大工作集 $W_x$ 的区间 $x$
2. **着色**：将 $W_x$ 中所有区间着为新颜色 $c^*$
3. **递归**：在 $I' = I \setminus W_x$ 上递归着色

**归纳步骤**：
- 由引理 3.13：$cost(I) \leq cost(I') + 2|W_x| \log |W_x|$
- 由能量定义：$E(C) = E(C') + 2|W_x| \log |W_x|$
- 由归纳假设：$E(C') \geq cost(I')$
- 因此：$E(C) = E(C') + 2|W_x| \log |W_x| \geq cost(I') + 2|W_x| \log |W_x| \geq cost(I)$ ✓

### 4.4 完成证明（命题 3.2）

由引理 3.14，总是存在 $C$ 使得 $E(C) \geq cost(I)$。
由引理 3.12，这蕴含 DeleteMin 总代价 = $O(OPT_Q(G) + n)$。

## 核心直觉总结

| 层面 | 上界（算法做了什么） | 下界（对手能构造什么） |
|------|---------------------|---------------------|
| 数据结构 | DeleteMin 代价 = $\sum \log|W_x|$ | — |
| 图论 | — | 障碍序列贡献 $\Omega(\sum |B_i| \log |B_i|)$ |
| 信息论 | — | 比较次数 ≥ $\log_3$(线性化数) |
| **匹配** | **$cost(I)$** | **$E(C)$** |

**核心洞察**：Dijkstra 运行时的最大工作集 $W_u$ 恰好是某时刻探索树的"叶子层"——一个天然障碍。贪婪地将图分解为障碍序列，使得下界总和 ≥ 上界的常数倍。
